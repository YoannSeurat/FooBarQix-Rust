# Number To LCD

A small Rust command-line program that prints the number entered by the user as an LCD display.

## Run

```bash
cargo run
```

Then enter a number when prompted.

## Example

```text
Please enter a number : 
123
     _  _  
  |  _| _| 
  | |_  _|

Please enter a number : 
4509
     _   _   _  
|_| |_  | | |_| 
  |  _| |_|  _| 

Please enter a number : 
hello
Wrong number format ! invalid digit found in string
```

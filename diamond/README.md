# Diamond

A small command-line program that prints a diamond starting with 'A' with the supplied letter at the widest point.

## Run

```bash
cargo run
```

Then enter a letter of the alphabet when prompted.

## Example

```text
Please enter a letter of the alphabet :
C
  A
 B B
C   C
 B B
  A

Please enter a letter of the alphabet :
f
     A
    B B
   C   C
  D     D
 E       E
F         F
 E       E
  D     D
   C   C
    B B
     A
```
